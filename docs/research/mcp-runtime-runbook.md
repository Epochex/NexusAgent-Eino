# MCP 运行与授权

## 接入与升级

当前平台使用官方 Go SDK 1.8.0，支持 Streamable HTTP 的 JSON/SSE 响应，已分别与现代无状态协议和旧版 initialize/initialized 会话服务联调。独立旧式 SSE、stdio 本地进程、交互式 sampling/elicitation、多轮回传和自动重连未启用，管理界面不再提供这些不可执行的选项。协议来源见 [核对记录](2026-10-20-integration-protocols.md)。

先执行数据库迁移至 011，再部署同一版本 server/worker。升级前保存数据库备份和原有主密钥；更换密钥会使现存凭据无法解密。旧 MCP 工具策略统一转为 dangerous/manual，不能沿用未经审阅的“只读”声明。旧明文配置不会在启动期间静默改写，也不会在管理响应中回显；管理员使用“加密迁移”或显式同步操作，将 headers 及历史 command/args/env 归档进 AES-GCM 加密信封，并清空原始明文字段。HTTP 接入不会执行归档的历史命令。011 的 down 保留授权/加密字段，不会把凭据降回明文；回滚应使用兼容此迁移的应用版本，不能直接恢复旧不安全二进制。

出站默认只允许公网目标。运营者若需要私有 MCP 服务，在配置文件的 `outbound.private_origins` 中配置准确的 scheme/host/port，例如：

```yaml
outbound:
  private_origins:
    - https://tools.internal.example:8443
mcp:
  enabled: true
```

这不是按路径授权。内部许可不会开放链路本地/云元数据地址；DNS 解析后的实际地址和重定向仍受检查。HTTP 客户端不继承系统代理，鉴权头只发往允许的同 origin 端点。URL 中不接受用户信息、查询参数或片段；鉴权通过独立 headers 提供。

## 工具发现和权限

每个服务默认仅管理员可用，可明确授权最多 128 个用户 ID。执行前从 PostgreSQL 重新读取用户状态/角色、服务启停和授权，不能依赖旧 JWT 管理员角色或启动缓存。server 与 execution worker 在启动时只从数据库恢复工具处理器，不需要启动时访问所有远端；动态注册分发也支持 worker 启动后同步的新工具。

同步先完整拉取并校验远端目录，再在事务中发布：最多 16 页、256 个工具、单 Schema 16 KiB、描述 4 KiB。只支持当前 Eino 可加载的 JSON Schema 子集和本地引用；不支持的关键字使整次同步失败，保留之前可用的绑定，避免“同步成功、Agent 无法使用”。有效 MCP 参数头注解由官方 SDK 编码处理。工具按照远端名称保留稳定 ID；删除的工具被停用，历史 Agent 绑定不能借旧注册表继续调用。

新工具默认需审批，恢复策略为 manual。管理员核查实际接口后，在“工具与策略”中设置：

| 策略 | 核查要求 | 恢复行为 |
| --- | --- | --- |
| manual | 不确认远端幂等保证 | 调用结果不确定时进入 needs_attention，人工核对 |
| readonly | 确认无副作用并记录依据 | 可在有限尝试预算内恢复 |
| idempotent | 确认远端以稳定操作号去重，并记录依据 | 使用相同 Idempotency-Key，在有限预算内恢复 |

远端 annotations 只是提示，不会自动提升权限。重试依据必须描述远端真实契约；平台无法证明管理员填写的声明。普通对话和管理调试只可直接使用已审阅、免审批的只读工具；写操作通过持久化工作流执行审批、调用与核对。管理员调试接口也不能绕过写审批。

服务编辑采用 config_version CAS，工具策略审阅采用 binding_version CAS。端点、鉴权、工具 Schema/描述、移除后恢复或策略变更使旧绑定授权失效；新增无关工具、重命名和授权列表变更不误伤未变化的工具，权限列表仍逐次检查。工作流冻结无密钥的远端来源、绑定版本和审阅依据，用于复查当时批准的对象。

## 执行边界

每次模型工具调用都重新确认 Agent 绑定、工具状态、Schema 和绑定版本；调用前最后一次服务检查仍比较预期绑定版本，防止检查后切换目标。参数必须是一个 JSON 对象，最多 64 KiB，保留大整数；验证失败不发送远端调用。一个 Agent 最多绑定 128 个工具，绑定 JSON 最多 64 KiB。

当前服务每次操作构造并关闭有界 SDK 会话；并发初始化由 SDK 包装器合并，但跨工具调用不复用服务级会话池。工具默认 30 秒上限，文本/结构化结果最多 64 KiB。非文本结果、交互式未完成结果和远端 isError 不会被伪装成成功。应用发出的工具 POST 不进行传输层隐式重试；工作流操作号只传给 tools/call，不传给 discovery/initialize。

## 验证和限制

测试使用官方 SDK 的本地标准协议服务，PostgreSQL 为真实实例。模型环节为确定性 HTTP 测试对端，不代表已通过真实模型回答质量、费用或吞吐验收。

已验证服务级事务回滚、稳定工具 ID、迁移前后明文清理与响应脱敏、用户授权/停用、旧管理员 JWT 撤权、策略 CAS、目标切换授权失效、无关目录变化保留授权、删除工具撤权；实际 Eino Agent 完成模型→MCP→模型闭环。

实际 cmd/worker 验证：启动后新增工具可执行；重启后调用恢复；审批写操作在远端产生效果、响应未提交时杀进程，替代进程进入 needs_attention，远端效果始终为 1 次。受控模型不参与该写故障测试。

浏览器完成登录、同步显示真实工具数、新工具默认禁止调试、审阅只读策略、实际返回、名称编辑、凭据不回显及刷新；最终截图：
